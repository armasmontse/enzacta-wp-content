# Implementation Prompt Template

## Section

Use exactly one value:

- HERO
- ICONS
- INFO
- HEALTH
- INSTRUCTIONS
- CAROUSEL
- FAQ
- FACTS
- FOOTER

## Objective

Describe the requested implementation outcome for the selected section.

## Scope

- Modify only the selected section.
- Do not modify any other section.
- Preserve EN and KO structural parity.
- Preserve existing class names, JavaScript hooks and stable functionality unless explicitly included in scope.

## Inputs

List only the approved content, design and asset references required by the selected section.

## Deliverables

List only the files authorized for modification.

## Acceptance Criteria

List the verifiable requirements for the selected section only.
