# Architecture Decisions

## Canonical Product Page Sections

- The canonical page architecture contains nine sections.
- The canonical order is: HERO, ICONS, INFO, HEALTH, INSTRUCTIONS, CAROUSEL, FAQ, FACTS, FOOTER.
- VIDEO is removed as a canonical section.
- HEALTH is a new canonical section.
- INSTRUCTIONS is a new canonical section.
- HERO, ICONS, INFO, CAROUSEL, FAQ, FACTS and FOOTER remain canonical sections.
- Every asset name must use the prefix of its canonical section.
